Created phashutil/phashutil_test.go containing a fully table-driven test suite for HammingDistance and Similarity. Covers three required scenarios: identical hashes (distance 0, similarity 1.0), bitwise-opposite hashes (distance 64, similarity 0.0), and a partial case with exactly 32 differing bits (distance 32, similarity 0.5). All assertions use exact value matches. The test file is placed in the same package directory to remain directly runnable alongside the implementation.
